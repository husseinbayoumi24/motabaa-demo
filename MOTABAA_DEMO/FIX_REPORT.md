# تقرير الإصلاحات — MOTABAA

كل بند من تقارير التدقيق (files 2 و 3) وحالته الفعلية. الاختبارات: **46 اختبار بينجحوا على PostgreSQL 16 الحقيقي وعلى SQLite** (منطق قاعدة البيانات + فتح كل صفحة لكل دور بالعربي والإنجليزي + الجلسات + الـ CSV والنصوص).

## الفصل بين النسختين
| | الإنتاج `MOTABAA_PRODUCTION` | التجربة `MOTABAA_DEMO` |
|---|---|---|
| قاعدة البيانات | PostgreSQL فقط، لا يوجد أي كود SQLite | SQLite فقط (`demo_data/motabaa_demo.db`) |
| بيانات / حسابات | لا شيء. لا مدير افتراضي | بيانات وهمية (`seed_demo.py`) |
| ملف القاعدة | `database/motabaa_postgres.sql` | بتتبني تلقائيًا |
| أمان الفصل | | بترفض تشتغل لو في متغير PostgreSQL، ولا تقبل اسم ملف إنتاج (SEC-18) |
الكود المشترك (`app.py`, `db.py`...) واحد في النسختين، والفرق في `dbdriver.py` و`edition.py` فقط.

## الأخطاء
BUG-01 تعارض السنة بين الكليات: اتصلح (ومختبر). BUG-02 الـ pivot: اتصلح. BUG-03 كود الطالب بحروف كبيرة: اتصلح. BUG-04 `parse_role`: اتصلح. BUG-05 اسم الكلية في الإيميل: اتصلح (من إعدادات الجامعة). BUG-06 الجلسات القديمة: اتصلح.
**أخطاء إضافية لقيتها بالاختبار واتصلحت:** مفتاح عنصر مكرر `kpis` بيكسر داشبورد الكلية، جدول بعمودين بنفس الاسم بيكسر نفس الصفحة، حماية CSV كانت بتفشل مع pandas 3، و`days_since` كان ممكن يطلع -1 بسبب تقريب الثواني.

## قاعدة البيانات
DB-01 PostgreSQL: **اتنفذ** (مجموعة اتصالات `psycopg_pool`، أنواع صح، فحص نسخة الـ schema عند التشغيل). DB-05: **جزئي** (مفتاح مركب: الدكتور لازم يكون من نفس كلية المادة؛ باقي العلاقات متحققة في الكود). DB-06 = BUG-01. DB-07: **جزئي** (أكواد DR/DN/FA/AD محجوزة ومرفوضة للطلاب). DB-09: **اتصلح** (`RESTRICT` بدل `CASCADE` على سجلات الحضور والحسابات). DB-10: **اتصلح** (منطقة زمنية واحدة `Africa/Cairo` قابلة للتغيير). DB-11: **اتصلح** (`schema_version` + `scripts/migrate.py` بقفل). DB-12: **اتصلح** (CHECK في الجدولين). DB-13: **اتصلح** (تنظيف دوري). DB-14: **اتصلح** (`backup_postgres.sh`، جربت نسخ واستعادة فعليًا). DB-16: ملف الـ demo SQL مش موجود.

## اللي **ماعملتوش** (قرارات منتج، مش إصلاحات)
DB-02 الفصل الدراسي (Term)، DB-03 جدول التسجيل (Enrollment)، DB-04 ترقية الطلاب/الأرشفة، DB-08 تكرار اسم الدكتور في `courses`، DB-15 البريد الفريد على مستوى النظام. دي محتاجة قرار منك وبعدين مرحلة مستقلة. كمان ما أضفتش شاشات تعديل/حذف للمواد (مش موجودة أصلًا).

## حاجات لازم تعرفها
* اتشال رفع ملفات SQLite من شاشة الاستيراد (xlsx/csv/txt/json فقط).
* كود الحضور العشوائي بقى 6 أرقام (يدويًا 4–10 حروف/أرقام زي ما كان).
* **لم أختبر** زرار الـ GPS بمتصفح وجهاز حقيقيين (الاختبار الآلي مش بيشغّل المكوّن ده)، ولا ضغط حمل. شغّل تجربة على موبايل قبل الاستخدام الحقيقي.
* لو بتشغل أكتر من process: الكاش الصغير للكليات بيتحدّث خلال 15–30 ثانية.
